Tämä repositorio on luotu ROMA vuosikirjassa julkaistua artikkelia "Ciceron kirjeet erottuvat muusta latinasta - käyttökonteksti heijastuu kielioppiin" varten.

Tästä repositoriosta löydät pienimuotoiseen tutkielmaan liittyviä lisäkuvaajia ja tarkkaresoluutioisen version pääkomponenttianalyysin kuvaajasta. 

Analyysia varten luotu koodi perustuu tutkimusartikkeliin

1 University of Turku
2 Helsingin yliopisto = Helsingfors universitet = University of Helsinki
